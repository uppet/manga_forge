# Choice icon atlases

These UI icon atlases were generated with OpenAI image generation for the
Last Inkwarden demo, then mapped explicitly by content ID in
`scripts/choice_icons.gd`.

- `upgrade-icons-v1.png`: sixteen semantic technique icons in a 4×4 atlas.
- `relic-icons-v1.png`: twelve unique relic icons in a 3×4 atlas.

Both atlases use transparent backgrounds and the palette in `art-bible.yaml`.
The runtime uses atlas regions and nearest filtering; no generated lettering is
displayed.
