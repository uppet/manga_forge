# Boss introduction portraits

The Editor, Binder, and Author cut-ins were generated with OpenAI image
generation, using `assets/characters/combat-cast-atlas-v1.png` as the identity
reference. They are runtime boss-introduction art for the Last Inkwarden demo.

The left side of each 3:2 composition is intentionally quiet so localized title
copy can be rendered by Godot. Generated lettering is never used.
